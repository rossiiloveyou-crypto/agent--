此文件夹是**并行模式**的隔离区（规范 §6.3）。日常是空的，只在启用并行时才用。

## 怎么用（三步）

1. **执行者**：把项目仓库拷进这里，命名 `<任务名>-PHASE<n>-Workspace`（或 `git worktree add`）。
   在这个副本里改代码、跑 build、跑回归 —— **不碰主仓**。
2. **执行者**：本 Phase 完成后，往 `AD.md` 追加一行（`AD-nn`），写清改了哪些文件、基于哪个提交、局部实测多少。
3. **人**：把 `AD.md` 拖给撰写者 → 撰写者按行并入主仓 → **并入后重测** → 更新 `BASELINE.txt`。

## 三条不能破的规则

- ❌ **workspace 里的 `BASELINE.txt` 只读**。测出的数记进 `AD.md`，不改文件。
  两个 Phase 各加测试时，各自只能看见自己那一半；写回去会把主仓基线改成错的数。
- ❌ **执行者不并入主仓**。并入是撰写者的活，且必须由人搬运 `AD.md`。
- ❌ **不装包时才能用 junction 共享 `node_modules`**。junction 是写穿透的，
  在一个 workspace 里 `pnpm install` 会改掉主仓的依赖，而主仓那边毫不知情。
